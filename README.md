🔍 Custom Object Detection with YOLOv8
This project demonstrates a custom object detection model trained using YOLOv8, capable of detecting three distinct classes:

👤 Humans

🚗 Cars

🔥 Fire

The model has been trained on a labeled dataset specific to these classes and supports real-time detection, making it suitable for surveillance, traffic monitoring, and fire hazard alert systems.
